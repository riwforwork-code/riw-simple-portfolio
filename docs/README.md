# Pakkapon Riw | Data Analyst Portfolio

A minimalist, high-impact portfolio website designed to showcase data analysis projects and professional expertise.

## 🚀 Features
- **"Deep Space" Aesthetic:** A modern dark theme optimized for readability and a professional "data/code" look.
- **Responsive Design:** Fully functional across desktop and mobile devices.
- **Project Showcases:** High-impact data analysis project cards featuring tech stacks and key insights.
- **Interactive Elements:** Smooth navigation and a clean UI using Vanilla CSS and JetBrains Mono typography.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for SEO and accessibility.
- **CSS3:** Custom layout using Flexbox and CSS Grid.
- **Typography:** JetBrains Mono via Google Fonts.

## 📂 Project Highlights
1. **E-commerce Customer Segmentation:** RFM analysis using Python and SQL to drive targeted marketing.
2. **Financial Dashboard:** Interactive visualizations for real-time financial tracking.
3. **Predictive Sales Model:** Time-series forecasting using Scikit-learn.
